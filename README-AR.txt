M.S.F مساعد المبيعات - الإصدار 1.2

التعديلات:
- نقل التخزين الأساسي من localStorage المحدود إلى ملف JSON داخل مساحة التطبيق الخاصة على الهاتف.
- نقل البيانات القديمة تلقائياً عند أول تشغيل بعد التحديث، إذا كانت موجودة.
- حفظ البيانات بصورة متزامنة قبل إظهار نجاح الحفظ.
- ضغط الصور إلى JPEG بعرض/ارتفاع أقصى 720 بكسل وجودة 62% لتقليل المساحة.
- الإبقاء على إضافة حتى 3 صور للمنتج وعارض تكبير/تصغير الصور.
- لا يوجد حد عددي برمجي لعدد المنتجات.
- المحافظة على الواجهة الحالية السوداء والذهبية.

طريقة الاستخدام:
1. ارفع محتويات هذا الملف المضغوط إلى مستودع MSF-Android-App مع الحفاظ على مسارات المجلدات.
2. انتظر نجاح GitHub Actions.
3. نزّل APK وثبّته كتحديث فوق النسخة الحالية، ولا تحذف التطبيق ولا تمسح بياناته.
4. افتح التطبيق واتركه لحظات حتى ينقل البيانات القديمة تلقائياً.
5. اختبر وجود المنتجات القديمة ثم جرّب إضافة منتج جديد.

تنبيه مهم:
لا تحذف النسخة الحالية ولا تستخدم Clear data / مسح البيانات. خذ نسخة احتياطية من شاشة النسخ الاحتياطي قبل التحديث إن أمكن.
التخزين الداخلي الخاص بالتطبيق لا يعني تخزيناً سحابياً أو مزامنة بين الأجهزة؛ النسخ الاحتياطي يظل مهماً عند تغيير الهاتف أو حذف التطبيق.
